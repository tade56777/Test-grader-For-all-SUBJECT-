About Test Grader

Test Grader is a powerful Python application designed to help educators and students calculate and visualize test scores. With an intuitive interface and comprehensive grading scale, it provides detailed feedback and visual representation of test performance.

How to Use

  1. Download the Python script using the button above
  2. Make sure you have Python installed on your computer
  3. Run the script using Python: python "test grader V6.0.0.py"
  4. Enter the test score when prompted
  5. View the detailed results, including letter grade and feedback
  6. Optionally grade additional tests without restarting the program
